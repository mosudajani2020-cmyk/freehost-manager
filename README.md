# FreeHost Manager

FreeHost Manager is a web hosting management platform designed to provide
users with a simple interface for managing websites, files, databases,
domains, hosting resources, and related services.

## Project Status

🚧 Development

## Technology

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- PHP
- MySQL/MariaDB
- Apache
- Node.js
- Git/GitHub

## Development Environment

This project is currently being developed locally using AppServ.

## Security

Security is a core requirement of this project.

The system will include:

- Secure authentication
- Password hashing
- Role-based access control
- CSRF protection
- Input validation
- SQL injection prevention
- Secure file handling
- Audit logging
- User/resource isolation
- Rate limiting
